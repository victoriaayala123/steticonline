# Relevamiento del proyecto Steticonline

## 1. Descripción del proyecto

Steticonline será un sistema web para la gestión y reserva de turnos de una estética.

El sistema contará con una landing page pública donde los clientes podrán conocer los servicios ofrecidos y solicitar turnos online.

También contará con un panel privado para que el administrador pueda gestionar las reservas.
